# Personal Portfolio

## Oasis Infobyte Web Development & Designing Internship 

## Objective
A responsive personal portfolio website built using HTML5 and CSS3 as part of the Oasis Infobyte Web Development & Designing Internship (Level 1 - Task 2).

## Description

This project is a responsive personal portfolio website that showcases my profile, technical skills, projects, and contact information. It features a professional hero section with an avatar, an About Me section, a skills section highlighting my technical expertise, a projects section with GitHub repository and live demo links, and a contact section containing my email, GitHub, and LinkedIn profiles. The website also includes a downloadable resume, smooth scrolling navigation, and a clean, modern interface built using **HTML5** and **CSS3**.

## Features
- Hero section with professional avatar
- About Me section
- Skills section
- Projects section with GitHub and Live Demo links
- Contact section with email, GitHub, and LinkedIn
- Smooth scrolling navigation
- Responsive design
- Resume download button

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Poppins)
- Font Awesome
