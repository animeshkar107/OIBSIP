# Landing Page (LearnHub)

## Oasis Infobyte Web Development & Designing Internship

## Objective
A responsive educational landing page built using HTML5 and CSS3 as part of the Oasis Infobyte Web Development & Designing Internship (Level 1 - Task 1).

## Description

**LearnHub** is a responsive educational landing page designed for an online learning platform. The website features a clean and modern interface that introduces users to the platform and its services. It includes a navigation bar with smooth scrolling, an engaging hero section with a call-to-action button, a features section highlighting the platform's advantages, a popular courses section, an about section describing LearnHub, and a contact section with email, location, and social media links. Built using **HTML5** and **CSS3**, the project emphasizes responsive design, user-friendly navigation, and an attractive layout for a better user experience.

## Features
- Responsive landing page design
- Navigation bar with smooth scrolling
- Hero section with call-to-action button
- Features section highlighting platform benefits
- Popular Courses section
- About LearnHub section
- Footer with contact section & social media icons
- Clean and modern user interface

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Poppins)
- Font Awesome
